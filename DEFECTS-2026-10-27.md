# Defect review — 2026-10-27

Sources: a live UI sweep over CDP (dev build) plus four code audits (core document lifecycle; Find in Files / Explorer / large files; Compare + code intelligence; Claude Code tabs + terminals). Each item was checked against the code; items marked **live** were also reproduced in the running app.

Status: ✅ fixed (commit) · ⏳ open · ➖ deferred (reason given)

**Outcome:** 48 of 49 items fixed, each in its own commit and verified with a type check, the unit tests (Vitest 196, cargo 84, both passing at the end) and, for all but a few pure-logic fixes, a scripted run of the app over CDP. One architecture item (A2) is deferred: it is a refactor with no user-visible defect.

New shared pieces introduced by the fixes: `src/lib/dialogs.ts` (queued dialogs, `choose()`), `editor.registerFocus()` (focus for non-text tabs), `src-tauri/src/writer.rs` (non-blocking child stdin), `search::parse_replacement` (JS `$` rules in Rust), `bigfile::Sep` (UTF-16-aware line ends), `src/lib/bigGeometry.ts`.
