Privacy policy

Effective 26 November 2026

In short: Quarry does not collect, store or share any personal information. It has no accounts, no analytics, no telemetry and no advertising. Your files stay on your PC, and the developer of Quarry receives nothing from the app. If you buy a commercial license, the details you give at checkout are used only for that order: see Buying a commercial license.

Who this covers

This policy covers Quarry, a text and code editor for Windows published by Stephen Shirey ("the developer"), however you installed it: from the Microsoft Store or from the releases page on GitHub.

Information the developer collects

None. Quarry does not send the developer your files, file names, settings, usage statistics, crash reports, device identifiers or anything else. The developer runs no servers for Quarry.

What stays on your PC

Quarry reads and writes the files you open, in place. It also keeps a few files of its own in your Windows user profile, which never leave your PC:

  • %APPDATA%\com.quarry.app: your settings, your session (the open folder and tabs, the text of untitled tabs and of unsaved changes to files, recent files and folders, panel layout), find and replace history, your scripts and macros, and the API requests you save (header values marked secret are encrypted with Windows' Data Protection API, so only your Windows account can read them).
  • %LOCALAPPDATA%\com.quarry.app: a crash log, written only if Quarry crashes and shown only to you, backups for undoing the last Replace in Files (removed by the next one, by undoing, or after a week), and the app's own browser storage (the previous values of settings you changed, recently used commands, and the name of the GitHub account you picked).

Replace All in a large file writes a temporary working copy of that file to your Windows temporary folder, which Quarry removes when it is no longer needed. Responses to API requests are received into that folder too; Quarry removes each one once it is in a tab, and a large one after a day.

Uninstalling Quarry and deleting those two folders removes everything it stored.

Network connections Quarry makes

Quarry works offline. It connects to the internet only in the cases below, and each connection goes from your PC straight to the service named. As with any internet connection, that service sees your IP address.

Checking for updates

When it starts, Quarry asks GitHub whether a newer release exists, and downloads the update from GitHub if you accept it. No information about you or your files is sent. You can turn this off with Settings › Check for updates on start. GitHub handles the request under the GitHub Privacy Statement.

Git

Quarry's Git features run the git program installed on your PC. Fetch, pull and push contact the remotes configured in your repository, using your own Git configuration and credentials. While a repository with a remote is open, Quarry may fetch from that remote in the background to show whether you are ahead or behind.

GitHub

Quarry contacts api.github.com in two cases. When you ask it to create a repository on GitHub, it obtains your GitHub credential from Git's credential manager on your PC and sends it with that request. When the repository settings show a remote on github.com, it asks GitHub whether that repository is private or public: first without any credential, which answers for every public repository, and only if GitHub does not show the repository that way a second time with your credential, if you are signed in. The credential goes only to api.github.com. Quarry never stores it and never sends it anywhere else. Sign in opens Git Credential Manager's own sign-in window; the sign-in is between that program and GitHub.

API requests

When you click Send in the API Requests panel, Quarry sends that request, with the headers and body you typed, to the address you typed. If that server redirects the request, Quarry follows up to 10 redirects; it never follows one from https to plain http, never carries a header you marked secret (or Authorization / Cookie) to a different site, and sends the request nowhere else. Nothing is sent until you click Send.

Language servers and tools you install

Code intelligence uses language servers, which are separate programs from other publishers that run on your PC. If you accept Quarry's offer to install one, Quarry runs the install command shown (for example npm, rustup, go, winget or dotnet), which downloads the server from that tool's own registry. Those programs and registries follow their own privacy policies.

Programs you run

Programs you start in a terminal tab, and external formatters you have installed, are yours: what they do on the network is up to them, not Quarry.

Buying a commercial license

Online orders are processed by Paddle.com, our reseller and the merchant of record. Paddle collects your payment details and processes your order under the Paddle Privacy Policy. The developer never sees your card or bank details.

From Paddle, the developer receives what is needed to keep a record of the licenses and to help you: your name, email address, company name, country, postal code, business tax number if you gave one, and the number of users, the amount and the dates of your payments. If you buy by invoice directly from the developer, the developer keeps the same details from your order and your emails. They are used only to record the licenses, answer you about your order and meet tax and accounting obligations. They are kept for as long as tax law requires, then deleted, and they are never sold or used for marketing.

You can ask to see, correct or delete these details by writing to the address below, except where the law requires them to be kept.

On this website

The website has no analytics, cookies or advertising. Paddle's checkout script loads only when you click Buy licenses; until then your browser loads nothing from Paddle. The download button asks GitHub for the newest release, so GitHub sees your IP address when the page loads.

Sharing with third parties

The developer has no personal information from the app, and so shares none of it. Details from a license order are shared only with Paddle, which processed it, and with tax authorities or others where the law requires. They are never sold.

Microsoft Store

If you install Quarry from the Microsoft Store, Microsoft processes the installation under the Microsoft Privacy Statement. Microsoft may give the developer aggregated figures such as install counts, which do not identify you.

Children

Quarry is a general-purpose developer tool. It is not directed at children and collects no information from anyone.

Changes to this policy

If Quarry's behaviour changes in a way that affects this policy, this page will be updated together with the release that changes it, and the date at the top will change.
