Installing Quarry

Quarry runs on Windows 11, 64-bit (x64). It is free for individuals; an organization with two or more people using it needs a commercial license (see License).

Install

  1. Open the latest release.
  2. Under Assets, download Quarry_<version>_x64-setup.exe (about 7 MB).
  3. Run it and follow the two steps of the installer. Quarry starts from the Start menu.

The installer needs no administrator rights: it installs for your Windows account only, into %LOCALAPPDATA%\Quarry. It does not change your default apps. You can choose another folder, as long as it is one your account can write to: a folder that needs administrator rights, such as C:\Program Files, is refused with a message and nothing is installed.

Which file is which

FileWhat it is
Quarry_<version>_x64-setup.exeThe installer. This is the one you want.
latest.jsonUsed by Quarry's own updater. You never need to download it.
Source code (zip, tar.gz)Added by GitHub to every release. They hold only these guides and the website, not Quarry itself.

A PC with no internet access and no WebView2 (Windows 11 comes with it) can use the installer made for the Microsoft Store instead, which has WebView2 inside (about 290 MB): https://quarrydist.blob.core.windows.net/releases/v<version>/Quarry_<version>_x64-store-setup.exe, with the version number of the release in both places.

Checking the download

Releases are code-signed. Right-click the downloaded file, choose Properties › Digital Signatures, and the signer is Stephen Shirey. If Windows asks whether to run the file, the publisher shown is the same name.

Windows SmartScreen can still show "Windows protected your PC" for a release that few people have downloaded yet. Check the publisher as above, then choose More info › Run anyway.

What the installer adds

  • Quarry in the Start menu, and in Settings › Apps › Installed apps.
  • Open with Quarry in File Explorer's right-click menu for files, and Open folder in Quarry for folders (on Windows 11 under Show more options).
  • Quarry in the Open with list for common text, data and code files.

Updates

Quarry looks for a new version when it starts and offers to install it. The update is downloaded from GitHub, verified against Quarry's signing key, installed in a small progress window, and Quarry restarts with your tabs. It will not update while you have unsaved changes.

  • Check yourself: Help › Check for Updates.
  • Turn the check at start off: Settings › App › Check for updates on start.
  • See which version you have: Help › About Quarry.

Uninstall

Settings › Apps › Installed apps › Quarry › Uninstall. This removes the app and the File Explorer entries.

Your settings, session, scripts and macros are in %APPDATA%\com.quarry.app, and logs in %LOCALAPPDATA%\com.quarry.app. Delete those two folders to remove everything Quarry stored (Settings: Files Quarry keeps).

Installing on many PCs

For scripted installs, run the installer silently:

Quarry_<version>_x64-setup.exe /S

It still installs per user, so run it as the user who will use Quarry. An organization installing Quarry for two or more people needs commercial licenses: see License.
